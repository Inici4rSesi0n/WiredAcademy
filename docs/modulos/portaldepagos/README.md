# Portal de Pagos (Autogestión)

---

## 1. Visión General

Es un portal externo diseñado para que los estudiantes y padres de familia visualicen sus deudas pendientes (pensiones, matrículas) y realicen sus pagos en línea.

---

## 2. Control de Acceso (RBAC)

- **Roles con visibilidad:** `ESTUDIANTE`.
- **Acceso de Padre:** Indirecto (paga las deudas del hijo seleccionado).
