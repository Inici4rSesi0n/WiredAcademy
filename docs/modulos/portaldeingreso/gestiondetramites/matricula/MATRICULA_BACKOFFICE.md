# Módulo: Matrícula (Back-Office)
## 1. Visión General
Operación presencial y masiva de matrículas.
## 2. Control de Acceso
- `SECRETARIO`, `COORDINADOR`, `ADMINISTRADOR`.
## 3. Requisitos Funcionales
- **Colegios/Institutos:** Selección de un Grupo (se asignan todas las materias).
- **Universidades:** Panel dinámico para elegir sección por asignatura.
- **Excepciones:** Permite forzar matrículas fuera del flujo regular.
