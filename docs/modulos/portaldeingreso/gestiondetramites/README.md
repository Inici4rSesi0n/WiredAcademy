# Back-Office: Gestión de Trámites (Operativo)

---

## 1. Visión General

Esta sección es el **Back-Office**. Está diseñada para los roles operativos que atienden a estudiantes de forma presencial o masiva, o que necesitan forzar procesos administrativos.

---

## 2. Control de Acceso (RBAC)

- **Roles con visibilidad:** `SECRETARIO`, `COORDINADOR`, `DIRECTOR`, `ADMINISTRADOR`.
- **Restricción:** Los estudiantes y docentes **NO** ven esta opción.

---

## 3. Sub-módulos

- **Matrícula (Back-Office):**
  - Registro presencial masivo (ej. matricular a un grupo entero).
  - **Excepciones Curriculares:** Aquí el Secretario o Coordinador **SÍ puede** matricular a un estudiante en un grado/ciclo diferente al que le toca por sistema (ej. el alumno repite un curso o se cambió de carrera), ya que requiere validación humana.
- **Pagos (Back-Office):** Registro de pagos en efectivo en caja, emisión de recibos.
- **Trámites (Back-Office):** Aprobación de becas o solicitudes SAE.
