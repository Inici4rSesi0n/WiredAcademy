# Portal de Ingreso

Es el dashboard principal compartido por todos los usuarios.

---

## 1. Navegación

El menú lateral (`sidebar`) se renderiza dinámicamente usando `GestionPermisos`. Las opciones no permitidas para el rol actual se ocultan.

---

## 2. Vistas Adaptativas

Algunos módulos como "Configuración" cambian su contenido (FXML) dependiendo del rol del usuario logueado.
