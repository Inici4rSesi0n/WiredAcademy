# Módulo: Gestión de Usuarios
## 1. Visión General
CRUD de los 10 roles.
## 2. Control de Acceso
- `ADMINISTRADOR`, `DIRECTOR`, `SUBDIRECTOR`.
## 3. Requisitos Funcionales
- Formulario dinámico según rol.
- Validación de DNI internacional.
- Contraseñas BCrypt (factor 12).
- Código inmutable una vez creado.
