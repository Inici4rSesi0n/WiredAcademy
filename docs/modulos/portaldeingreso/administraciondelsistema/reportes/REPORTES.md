# Módulo: Reportes (BI)
## 1. Visión General
Información estratégica para la toma de decisiones.
## 2. Control de Acceso
- `ADMINISTRADOR`, `DIRECTOR`, `SUBDIRECTOR`, `COORDINADOR`, `TESORERO`.

- **Económicos:** Recaudación, morosidad, impacto de becas.

- Exportación a PDF/Excel.
