# Portal de Matrícula (Autogestión)

---

## 1. Visión General

Es un portal externo que permite a los estudiantes matricularse en las asignaturas de su malla curricular para el próximo periodo académico, eligiendo su grupo y horario de preferencia.

---

## 2. Control de Acceso (RBAC)

- **Roles con visibilidad:** `ESTUDIANTE`.
- **Acceso de Padre:** Indirecto (matricula al hijo seleccionado).
