# Módulo: Matrícula (Autogestión)
## 1. Reglas de Progresión
- El sistema calcula el Grado/Ciclo según créditos aprobados o avance.
- **Colegios:** El alumno elige la Sección (ej. 5to A).
- **Universidades:** El alumno elige la sección para cada asignatura de su malla.
