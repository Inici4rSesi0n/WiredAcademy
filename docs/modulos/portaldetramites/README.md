# Portal de Trámites (Autogestión)

---

## 1. Visión General

Es un portal externo diseñado para que los estudiantes y docentes realicen sus solicitudes administrativas (constancias, certificados, rectificaciones) sin acudir a la institución.

---

## 2. Control de Acceso (RBAC)

- **Roles con visibilidad:** `ESTUDIANTE`, `DOCENTE`.
- **Acceso de Padre:** Indirecto (gestiona trámites del hijo seleccionado).
