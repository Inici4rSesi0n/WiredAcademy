# Glosario de Términos del Dominio

| Término | Definición |
| :--- | :--- |
| **Usuario** | Entidad base para todos los actores. 10 roles definidos. |
| **TIPO_INSTITUCION** | Configuración global (COLEGIO, INSTITUTO, UNIVERSIDAD) que altera la lógica de matrícula. |
| **PeriodoAcademico** | Bloque de tiempo (ej. "2026-I"). |
| **Grado** | Nivel educativo (ej. "1er Grado"). |
| **Grupo** | Subdivisión de un Grado (ej. "1A") o Sección Universitaria. |
| **Clase** | Evento de enseñanza en una Franja Horaria. |
| **Recreo** | Evento de descanso asociado a Periodos. |
| **Matrícula** | Acto de vinculación del Estudiante con el Periodo y Grupo. |
| **Contrato B1** | Regla de que los Casos de Uso son la única fuente de eventos. |
